# 墨知桌面 · 和 Claude 一起读书

本地 PDF / EPUB 阅读器 + Claude Code 伴读。阅读器跑在浏览器里，Claude 在终端（或 Claude App 的 Remote Control）里陪你读：知道你读到哪、能检索全书、看得到书里的图，会在书页上留批注、写章节笔记。

不经过任何第三方服务：书、进度、批注都存在本机，Claude 通过 Claude Code 自己的订阅运行（MCP 是 Claude Code 主动来读阅读器，不是反向代理）。

## 用法

1. 把书（PDF / EPUB，可以有子文件夹）放进 `E:\cc伴读\书库`。
2. 双击 **`启动阅读器.bat`**，浏览器会打开书库。第一次会在后台解析书、建语义索引（模型约 118MB，下载到 `%USERPROFILE%\.cache\moread-desk`）。
3. 在本目录打开 Claude Code：
   - **普通模式**：`claude`。你在终端说话时，Claude 自动知道你读到哪、选中了什么。
   - **伴读模式（推荐）**：双击 **`和Claude一起读.bat`**。在阅读器里选中文字点「问 Claude」、在侧栏留言、回复批注，Claude 都会实时收到，回答也发回阅读器侧栏，不用切回终端。原理：会话启动时自动运行 `/companion`，Claude 用 Monitor 工具挂一个监听脚本（`scripts/watch.mjs`），阅读器里有新消息就唤醒它。第一次会询问是否允许运行 `node scripts/watch.mjs`，选允许并不再询问。如果监听意外停了，在终端输入 `/companion` 即可恢复，期间的消息不会丢。
   - 第一次会询问是否启用本项目的 `moread` MCP 服务器，选同意。

## 阅读器

- **选中文字** → 四色划线（可在设置里加自选颜色）/ 波浪线 / 问 Claude / 复制
- **点划线** → 查看批注和讨论，可以回复（回复会发给 Claude）
- **侧栏**：目录（✓ 标出已读，另有 大纲 / 术语 / 书签 三个子页）、批注（我的 / Claude 的）、笔记（含 Claude 写的学习摘要和它记住的事）、伴读对话、查找（精确 + 按意思）
- **顶栏**：Claude 在线状态、查找、书签 ☆、主题（跟随系统 / 浅色 / 深色）
- **导出**：笔记页「导出 Markdown」把这本书的摘要、大纲、术语、划线、笔记、对话导成一个文件
- PDF：连续滚动，A− / A+ 缩放，← → 翻页；EPUB：翻页 / 滚动切换，A− / A+ 字号
- 记录阅读时长：只在阅读器在前台、窗口有焦点、3 分钟内有操作时计时；书开着但没在读的时间另记，不算进阅读时长
- **读完**：读到正文结尾（书末的参考文献、索引等不用翻）自动标记「已读完」，重翻不会改掉；没翻到最后也可以点顶栏「标记读完」
- **目录坏了**（比如扫描版 PDF 每页一个页码书签）：目录面板里点「请 Claude 根据书里的目录页重建」，原目录保留，可以随时恢复

## 扫描版 PDF：本机文字识别

扫描版的页面只是图片，不能查找、划线，Claude 也只能一页页看图（很费用量）。书库里扫描版的书下面有「识别文字」按钮，阅读器顶栏也有。点了之后：

- 用 [RapidOCR](https://github.com/RapidAI/RapidOCR) 在本机识别，**不联网、不上传**；识别出的文字标着「本机识别文字」。
- 一次识别一本，其余排队；从你读到的那页往后先识别。识别完的页马上能选中文字、划线（叠了一层透明文字），每几十页并入一次检索和 Claude 的原文。
- 速度约 4~5 秒一页（这台电脑上 360 页约半小时），在后台低优先级运行，可以随时暂停，下次接着识别；服务重启也会自动接着识别。
- 结果存在 `data/books/<id>/ocr.json`，原 PDF 不改。偶尔有错字，Claude 读到不通的地方会看原页核对。
- 依赖：`pip install rapidocr onnxruntime pypdfium2`。Python 不在 PATH 上时，在 `config.json` 里设 `"ocr": { "python": "完整路径" }`。

## 其他页面（书库顶部导航）

- **回顾**：跨书浏览所有划线和笔记，按书、我的 / Claude 的、关键词筛选，导出 Markdown；勾选几条发给 Claude 串讲或出题。
- **足迹**：陪伴足迹（认识 Claude 第几天、交流轮数、一起读的书、常在什么时段聊书、按天的时间线）和阅读统计（时长、连续天数、近半年热力图、每本书的用时）。
- **设置**：主动陪读的开关与额度、防剧透、主题、管理 Claude 的长期记忆。

## 主动陪读

只在**伴读模式**下生效（普通模式下 Claude 没法自己开口）。默认：

| 行为 | 默认 | 说明 |
| --- | --- | --- |
| 随读段评 | 开，读完一章后 | Claude 读这一章留批注。两种分段：**按章节**（一章一次，条数按篇幅，默认每 10 页最多 4 条）或**按页数分段**（长章每 10 页一次，每次条数固定）。每天最多 10 条。也可改成「进入章节时」 |
| 整理术语 | 开 | 读完一章时把新概念记进术语表 |
| 章节大纲 | 关 | 读完一章时写要点大纲（随时可在 目录 → 大纲 里手动请求） |
| 卡住时问一句 | 开，8 分钟 | 同一页停留太久 |
| 回来时打招呼 | 开，隔 6 小时 | 简短回顾上次读到哪 |
| 记录学习进度 | 开，读满 15 分钟 | 一段阅读结束后静默更新学习摘要与长期记忆。不满 15 分钟的几段会攒起来；Claude 不在线时等它上线再补；读完整本书时写一版读完时的摘要 |
| 休息提醒 | 关 | |

「读完一章」的判定：翻到下一章，且这一章至少认真读了 3 分钟（快速翻过不算）。所有主动行为每天合计最多 20 次。
这些都占用你的 Claude 订阅用量，不额外花钱；觉得打扰或用量紧张，在设置页关掉即可。

## Claude 的工具（`moread` MCP）

| 工具 | 作用 |
| --- | --- |
| `get_reading_progress` | 当前书、页码、章节、选中文字、今日阅读时长 |
| `list_chapters` / `read_book_section` | 目录（标已读）、读原文 |
| `search_book` | 语义向量 + BM25 词法混合检索（RRF 融合） |
| `grep_book` | 字面 / 正则精确查找 |
| `view_page` | 把 PDF 某页渲染成图片给 Claude 看，可只看一块（放大小图）；不需要装 poppler |
| `get_image` | 看 EPUB 里的图 |
| `list_annotations` / `add_annotation` / `reply_annotation` | 批注与讨论 |
| `list_notes` / `write_note` | 读书笔记 |
| `say` / `get_questions` | 在阅读器侧栏说话 / 取阅读器里发来的消息 |
| `save_chapter_outline` / `list_outlines` | 章节大纲（每个要点可带原文依据） |
| `save_term` / `list_terms` | 术语表 |
| `save_book_summary` | 这本书的学习进度摘要（在旧版基础上增补） |
| `save_toc` | 书自带的目录坏了时，根据书里印的目录页重建 |
| `save_memory` / `recall_memory` | 跨书的长期记忆（理解、困惑、兴趣、习惯、进展） |

默认只读你读过的最远位置（防剧透，也让 Claude 跟着你的节奏），可在设置页关掉。

## 配置 `config.json`

| 项 | 默认 | 说明 |
| --- | --- | --- |
| `port` | 8848 | 改了要同步改 `.mcp.json` |
| `libraryDir` | `../书库` | 书库目录 |
| `spoilerGuard` | true | 防剧透的初始值（之后以设置页为准） |
| `embedding.enabled` | true | 关掉则只用词法检索 |
| `embedding.modelDir` | 用户目录 `.cache` | **必须是纯英文路径**（onnxruntime 在 Windows 上读不了中文路径） |

模型下载中断时可运行 `npm run fetch-model`（支持断点续传；国内网络可先设 `HF_ENDPOINT=https://hf-mirror.com`）。

## 数据与版本

- 所有数据在 `data/`：每本书一个文件夹（进度、批注、笔记、对话、大纲、术语、书签），以及全局的 `exchanges.json`（足迹流水）、`memories.json`、`settings.json`。备份就复制这个文件夹。
- 版本记录见 `CHANGELOG.md`。代码用 git 管理：`main` 是稳定版，每个版本打 tag（如 `v0.2.0`）；想回到旧版本可以 `git checkout v0.1.0`（`data/` 不受影响）。

## 已知限制

- 扫描版 PDF 没有文字层：不能检索、不能划线，但 Claude 仍可以用 `view_page` 看页面图片。
- 伴读模式下 Claude 每 30 分钟会重启一次监听（Monitor 的时长上限），会占用极少量用量。
- `server/channel.js` 是基于 Claude Code channels（研究预览）的旧方案，很多账号尚未开放，会被 Claude Code 静默丢弃，目前不再使用。
- 只监听 `127.0.0.1`，局域网其他设备访问不到。
